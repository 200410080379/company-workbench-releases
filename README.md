# 公司工作台 · 版本下载

员工档案、项目回本与分成、员工账户和税前工资管理的本地工具。Windows启动后在浏览器使用，账本保存在自己的电脑上。

[下载最新版本](https://github.com/200410080379/company-workbench-releases/releases/latest)

## 当前版本：0.21.0

- **历史月份直接更正**：工资、用工成本、公积金、项目成员比例与成本身份按选择的月份修改，后续自动联动；后面单独设置的标准保留。
- **项目类型与周期可纠错**：所有开发成员使用项目的统一开发周期；相关成本、分成和账本按差额重算。
- **已删除历史可更正**：保留已发生成本，修改历史不恢复未来分成。工资表手填实发保留。
- **完整数据迁移**：导出员工、项目、工资表、账户和历史记录为一个.swbackup文件，新电脑安装相同版本后导入。
- **导入前自动备份**：先显示替换范围，再整体替换；失败保留原账本。旧页面提示刷新，避免自动保存旧输入。

此前确定的自研收入先预留税费、广告回本、逐月人工预扣和代发行规则继续使用。自研默认20%为内部税费预留，不代表法定增值税税率或实际申报税额。

详见[0.21.0更新说明](https://github.com/200410080379/company-workbench-releases/releases/tag/v0.21.0)。升级保留原账本并自动备份；更正历史会重算相关月份，手填实发不变，不执行银行转账。

## 旧客户升级

- 软件内“版本与更新 → 检查更新”，下载并安装，无需登录GitHub。
- 离线更新：选择本版.swupdate文件安装。
- 更早版本：把Windows ZIP完整解压到新文件夹，保存网页修改并退出旧程序；运行新包中的“升级已有客户.cmd”，选择旧程序目录。升级后仍从原目录启动。

不要覆盖或删除原data目录。此前反馈的Windows更新EPERM目录改名失败及GitHub网络超时不在本次修复范围；遇到问题请保留原目录与备份。

## 新客户与更换电脑

首次使用：完整解压Windows ZIP后双击“公司工作台.exe”，无需另装Node.js；首次启动为正式空账本。

更换电脑：旧电脑打开“数据迁移与备份 → 导出全部数据”，将.swbackup文件带到新电脑。新电脑安装相同版本，选择备份文件，查看范围后导入。包含全部历史月份、余额、工资实发和未来收支。**导入整体替换当前账本，不合并两本数据；替换前会自动备份。** 员工Excel导出不能代替完整备份。

数据保存在程序旁的data目录。更新只下载程序，不上传账本；自动备份在data/backups。完整数据文件包含员工和工资资料，请妥善保管。
