# 公司工作台 · 版本下载

员工档案、项目回本与分成、员工账户和税前工资管理的本地工具。Windows启动后在浏览器使用，账本保存在自己的电脑上。

[下载最新版本](https://github.com/200410080379/company-workbench-releases/releases/latest)

## 当前版本：0.20.0

- **自研收入先预留税费**：默认20%，再用剩余收入回本和分成。该比例为内部预留，不是法定增值税税率或实际申报税额；各月使用该月保存的比例。
- **历史已回本项目的新广告先回本**：用预留后的收入回收广告／推广费，回本后分成；不再直接扣个人广告款。原扣款自动冲回，相关分成按差额调整。
- **人工预扣按月自动处理**：预扣项目开发期间的收入也可分成；不支持的成员变更明确报错。代发行保持独立计算规则。
- **直接修改自动保存**：已有项目金额、账户奖金和扣款可直接修改；千位分隔符支持统一，期初余额可补录和更正。
- 工资、公积金、实发继续自动联动，手工额外补缴与标准公积金分别记录。个人账户允许留存或借支。

**升级会重算未封存的历史分成、账户余额与工资表，手填实发保留；删除前封存记录保持原账。** 升级前自动备份，不自动清空项目，不执行银行转账。详见[本版更新说明](https://github.com/200410080379/company-workbench-releases/releases/tag/v0.20.0)。

## 旧客户升级

- 已接入在线更新的版本：软件内“版本与更新 → 检查更新”，下载并安装，无需登录GitHub。
- 离线升级：选择本版的.swupdate文件安装。
- 更早版本：完整解压Windows ZIP到新文件夹，保存旧网页修改并退出旧程序；运行新包中的“升级已有客户.cmd”，选择原程序目录。更新后仍从原目录启动。

不要覆盖或删除原目录中的data。此前反馈的Windows更新EPERM目录改名失败及GitHub网络超时不在本次修复范围；遇到问题请保留原目录与备份。

## 新客户使用与数据

完整解压Windows ZIP后双击“公司工作台.exe”，无需另装Node.js。通用安装包不包含任何真实员工、工资或项目数据，首次启动建立空账本。

账本在程序旁的data目录。更新只下载程序，不上传客户资料；备份在data/backups/before-update-*。迁移电脑前正常退出，再完整复制原程序文件夹。
