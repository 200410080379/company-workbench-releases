# 公司工作台 · 版本下载

用于员工档案、项目成本与分成、员工账户和税前工资核对的本地工具。Windows 启动后在浏览器中使用，账本保存在自己的电脑上。

[下载最新版本](https://github.com/200410080379/company-workbench-releases/releases/latest)

## 当前版本：0.18.0

新增 **项目管理 → 重新开始核算**，用于清除误录项目，再从历史月份重新录入。

点击入口只预览项目、工资表及账户余额变化。输入“清空项目并作废工资表”并确认后，系统先备份整本账本，再执行以下清理：

- 清空全部项目，包括此前已删除的项目，以及关联收入、开支、成员和成本记录。
- 清除项目带来的分成、人工预扣、开支扣款和返还。
- 旧工资表全部作废并保留原金额供查阅；清除工资表产生的工资入账和实发扣账，解除待发占用，允许在旧月份重新建表。
- 保留员工档案、岗位、工资标准、期初、手工奖金、个人入账和扣款，以及个人未来待生效安排。手工登记的实际发放也保留，请勿重复登记。

**升级不会自动清空数据。** 只有在新入口明确确认后才重置。执行前备份保存在 `data/backups/before-project-reset-*`，备份失败不清理；清理不能在页面一键撤销，需通过备份恢复。这只改变系统记录，不会追回已转给员工的钱。

保留 v0.17.0 的项目分成自动入账、员工资料与工资实发自动保存、基础工资统一在员工管理修改，以及工资表项目净额两行显示。

**已知限制**：本版未改动 Windows 更新器，此前反馈的 `EPERM` 目录改名失败尚未修复。出现该错误请保留原程序目录及 `data/backups` 中的备份。GitHub 连接超时的网络处理也未修改。

### 旧客户升级，保留原有数据

- **0.15.1及以上用户**：在软件内点击“版本与更新 → 检查更新”，下载安装即可，无需登录GitHub。
- **0.15.0 用户**：在原程序“版本与更新”中选择本次发布的 `staff-workbench-0.18.0.swupdate`，确认其他页面已保存后安装。此次升级会接入在线更新地址。
- **更早版本用户**：下载完整 Windows ZIP，解压到一个新文件夹；保存旧网页修改并在旧服务窗口按回车退出。运行新包中的“升级已有客户.cmd”，选择原程序目录。更新完成后仍从原目录启动。
- **以后更新**：在“版本与更新”中点击“检查更新”，下载并安装新版；也可使用离线更新包。

不要直接用新文件夹覆盖旧程序的 `data`，也不要为了更新删除原账本。

### 新客户首次使用

下载完整 Windows ZIP，完整解压后双击“公司工作台.exe”。无需另外安装 Node.js。通用发布包不包含任何真实员工、工资或项目数据，首次启动建立空账本。

## 数据与备份

账本在程序旁的 `data` 文件夹。更新只下载和替换程序，不上传客户资料。更新前自动建立 SQLite 备份，并用副本核对数据迁移；升级失败或新版首次启动失败时恢复更新前程序和账本。

备份在 `data/backups/before-update-*`。迁移电脑时先正常退出，再完整复制原程序文件夹。

## 验收范围

支持 Windows 10/11 x64。已完成程序测试、旧版账目迁移测试、签名和文件校验、失败恢复测试。Windows 双击升级流程仍需实机验收，EXE 暂未做 Windows 代码签名；更新包使用独立发布签名验证来源。

本工具计算税前数据，不执行银行转账。业务计算与最终工资请按公司实际情况核对。

本仓库用于发布通用软件和版本说明，不存放客户员工档案、工资数据库、备份或发布私钥。
