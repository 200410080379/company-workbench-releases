# 公司工作台 · 版本下载

员工档案、项目回本与分成、员工账户和税前工资管理的本地工具。Windows启动后在浏览器使用，账本保存在自己的电脑上。

[下载最新版本](https://github.com/200410080379/company-workbench-releases/releases/latest)

## 当前版本：0.22.0

- **默认显示上个月**：页面顶部突出工作年月，支持前后切月、回到上月及跨年选择。当前月、未来月有提示。
- **月份贯穿操作**：切换页面沿用所选月份，新增收支默认记在此月份，工资及收入标题显示具体年月。
- **删除误录并清除影响**：整个人员或项目录错时，先看余额变化和关联范围，再自动备份、清除、重算，之后可以重新建立。
- **两种删除各有用途**：普通删除保留历史；误录清除撤掉该对象全部历史影响。清除员工也会清除其工资、个人收支与未来安排，清除项目则保留员工工资和个人收支。
- **完整数据备份与迁移**：.swbackup文件包含员工、项目、工资表、账户及历史记录；操作前备份可下载并导入恢复。

**升级不会自动清空数据，也不会调整已有月份。** 员工、项目和原账本保留。综合回本、成本预扣、历史已回本和代发行的计算规则保持；默认20%为内部税费预留，不代表法定增值税税率或实际申报税额。

详见[0.22.0更新说明](https://github.com/200410080379/company-workbench-releases/releases/tag/v0.22.0)。

## 旧客户升级

- 软件内“版本与更新 → 检查更新”，下载并安装，无需登录GitHub。
- 离线更新：选择本版.swupdate文件安装。
- 更早版本：把Windows ZIP完整解压到新文件夹，保存网页修改并退出旧程序；运行新包中的“升级已有客户.cmd”，选择旧程序目录。升级后仍从原目录启动。

不要覆盖或删除原data目录。此前反馈的Windows更新EPERM目录改名失败及GitHub网络超时不在本次修复范围；遇到问题请保留原目录与备份。

## 首次使用、换电脑与恢复

完整解压Windows ZIP后双击“公司工作台.exe”，无需另装Node.js；正式账本首次启动为空。

换电脑时，在旧电脑“数据迁移与备份”导出全部数据，把.swbackup带到安装相同版本的新电脑导入。导入整体替换当前账本，不合并两本数据，并先自动备份。员工Excel导出不能代替完整备份。

特殊删除前的备份在“数据迁移与备份 → 操作前自动备份”中下载，导入后可恢复整本旧账。恢复之前应先导出当前数据，避免丢掉备份之后的新修改。

账本在程序旁的data目录，备份在data/backups。更新只下载程序，不上传员工资料；数据备份含完整员工及工资信息，请妥善保管。
