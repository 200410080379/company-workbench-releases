# 公司工作台 · 版本下载

员工档案、项目回本与分成、员工账户和税前工资管理的本地工具。Windows启动后在浏览器使用，账本保存在自己的电脑上。

[下载最新版本](https://github.com/200410080379/company-workbench-releases/releases/latest)

## 当前版本：0.24.0

- **公司总支出**：每位员工一个手填总额，可包含工资、社保、设备和软件费用；不拆明细，输入完成后自动保存。
- **仅供独立统计**：改值即替换，不自动累加，不随月份变化，不再加上工资，也不参与账户余额、工资或项目分成计算。
- **导出与迁移**：员工资料CSV、Excel及完整.swbackup备份均保留该数值，旧员工默认留空。
- **账户项目净额**：账户列表和详情按所选月份显示各项目增减，点击查看分成、扣款和返还。
- **流水汇总与项目进度**：同一来源的修改可折叠查看；项目录入完成状态按月份独立标记。

详见[0.24.0更新说明](https://github.com/200410080379/company-workbench-releases/releases/tag/v0.24.0)。

## 旧客户升级

- 软件内“版本与更新 → 检查更新”，下载并安装，无需登录GitHub。
- 离线更新：选择本版.swupdate文件安装。
- 更早版本：把Windows ZIP完整解压到新文件夹，保存网页修改并退出旧程序；运行新包中的“升级已有客户.cmd”，选择旧程序目录。升级后仍从原目录启动。

不要覆盖或删除原data目录。此前反馈的Windows更新EPERM目录改名失败及GitHub网络超时不在本次修复范围；遇到问题请保留原目录与备份。

## 首次使用、换电脑与恢复

完整解压Windows ZIP后双击“公司工作台.exe”，无需另装Node.js；正式账本首次启动为空。

换电脑时，在旧电脑“数据迁移与备份”导出全部数据，把.swbackup带到安装相同版本的新电脑导入。导入整体替换当前账本，不合并两本数据，并先自动备份。员工Excel导出不能代替整本备份。

操作前备份可在“数据迁移与备份 → 操作前自动备份”中下载，导入后恢复整本旧账。恢复前先导出当前数据，避免丢掉备份之后的新修改。

账本在程序旁的data目录，备份在data/backups。更新只下载程序，不上传员工资料；备份含完整员工及工资信息，请妥善保管。
